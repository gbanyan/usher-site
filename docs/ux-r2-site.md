# Round 2 公開站 UX／無障礙修正

## 本輪完成

- 首頁輪播只保留一個頁面主標題（H1）；後續投影片標題改為一般文字，避免同頁多個 H1。
- 將頁首背景圖視為裝飾圖，並為麵包屑提供繁中導覽名稱與隱藏分隔符號。
- 文章、病友故事、建議與指引、公告、相關報導及文件庫，明確區分「無內容」與「暫時無法載入」，錯誤狀態提供聯絡協會的下一步。
- 文件庫的下載連結加入文件／版本／檔名資訊，避免螢幕閱讀器只讀到重複的「下載」。
- 社群外部連結告知會在新視窗開啟。

## API 相容性

本輪未變更 Laravel API 契約。公開文件庫仍優先使用 `/public-documents`，並保留既有的 article 文件相容回退行為。

## 後續建議

- 待正式 API 環境可用時，以鍵盤與螢幕閱讀器實測輪播、行動版文件庫與各錯誤狀態。
- 將文章列表改用伺服器分頁與搜尋時，保留目前的空／錯誤狀態語意，並在資料量成長前避免一次取得大量資料。
